# 裂爪击抽取后未自动学习：根因与修复

## 已确认根因

用户实际日志 `dpcq-game-server/target/run-logs/server-20260908-194551.out.log`：

- 20:01:31，抽 1 次，累计 1。
- 20:02:13，抽 2 次，累计 3。
- 20:02:37，抽 4 次，累计 7。
- 20:03:51、20:03:53，客户端发送 75010，但当时缺处理器。

1. 第 6、7 抽的两张裂爪击均写入固定槽 12，后一张覆盖前一张。
2. 只执行第五抽引导节点，没有为本批第 6、7 抽发自动学习包。
3. 客户端有道具但没有已学技能，因此显示“可激活”，而不是可装配。后来抽到别的道具也不会补触发这次遗漏。
